# Рендеринг страниц

- / и /catalog: ISR, обновление не чаще одного раза в 300 секунд.
- /product/[slug]: ISR, 300 секунд, генерация при первом запросе; неизвестный товар возвращает notFound.
- /catalog/[slug]: SSR при каждом запросе, включая сортировку, фильтры и пагинацию из searchParams. Данные не кешируются.
- Корзина, избранное, авторизация, профиль и заказы сохраняют клиентскую интерактивность и не попадают в общий ISR-кеш.

Для сборки и выполнения нужен доступный API_URL (например http://localhost:5000/api). Запустите сервер до npm run build. При недоступном API ошибка не подменяется пустым каталогом или демо-данными.
Публичные данные читаются в Server Components и передаются интерактивным компонентам через props. Redux store создаётся для каждого дерева Providers, восстановление localStorage начинается после hydration и не скрывает серверный HTML.

Демо-данные: выполните npm run seed в AnimBook-server. SVG-иллюстрации поставляются в public/demo и не требуют внешнего сервиса.
